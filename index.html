Remote Desktop CALs for a small office: per user or per device, and how to set them up

Adam Shanin · 25 November 2026

When people in a small office work on a Windows Server through Remote Desktop, two kinds of licences are involved, and the second one is easy to forget. This page explains Remote Desktop Services (RDS) Client Access Licences: when you need them, how to count them per user or per device, and the setup steps that stop the "no Remote Desktop license servers available" error.

Two licences per person, not one

Every user or device that connects to Windows Server needs a Windows Server CAL. Anyone who also opens a Remote Desktop session to run programs on the server, for example an accounting app or Office on a terminal server, additionally needs an RDS CAL. Administrators connecting to manage the server are the exception: up to two simultaneous administrative sessions are included without RDS CALs.

Per user or per device

  • Per user covers one named person on any number of devices. It suits staff who connect from an office PC, a laptop at home and sometimes a phone.
  • Per device covers one device used by any number of people. It suits shared machines: a reception PC used by three shifts, or warehouse terminals.

Count both ways and pick the smaller number. Ten people with ten laptops and home PCs: 10 per-user CALs. Twelve staff in three shifts on four shared PCs: 4 per-device CALs. Per-user licensing needs Active Directory to be reported properly; in a small workgroup without a domain, per-device is the cleaner choice.

Versions must match or be newer

RDS CALs are version-specific. A Windows Server 2025 RDS CAL covers connections to Windows Server 2025 hosts and to earlier versions such as 2022 and 2019; a 2019 CAL does not cover a 2025 host. Buy CALs at the version of your newest RD Session Host.

Setting it up

  1. Install the Remote Desktop Licensing role and activate the licence server.
  2. Install the RDS CAL pack on the licence server.
  3. Set the licensing mode (Per User or Per Device) and point the RD Session Host at the licence server, through Server Manager or Group Policy.
  4. Check RD Licensing Diagnoser: it should show no warnings.

Until this is done, Windows Server allows Remote Desktop sessions for a 120-day grace period. When it ends, users see "no Remote Desktop license servers available" and cannot connect. Most cases of that error on small servers come from a licensing mode that was never set, or a CAL pack installed on a different server from the one the host points to.
